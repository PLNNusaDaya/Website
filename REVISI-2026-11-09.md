# Revisi PLTD Digital Logsheet V05 — 9 November 2026

Revisi ini mengikuti instruksi terakhir: empat indikator dihitung dari **stand hari ini − stand hari sebelumnya**, termasuk **Stand Pemakaian Oli Kumulatif (L)**. Aturan ini menggantikan rumus terbalik dan penjumlahan input oli harian dari revisi terdahulu.

## Perhitungan dan filter

- Per mesin dan tanggal, pilih jam/menit paling akhir yang tersedia pada **kedua hari**, di dalam jendela jam yang dipilih. Keempat indikator memakai pasangan record yang sama.
- Filter tanggal inklusif; jam mulai–selesai diterapkan pada setiap tanggal. Rentang jam terbalik ditolak. Untuk lintas tengah malam, pilih tanggal secara eksplisit dan pecah jendela harian jika diperlukan.
- Terapkan Filter mengaktifkan pilihan. Reset memakai tanggal saat ini dalam WIB. Filter aktif ditampilkan di layar.
- Satu hasil per mesin/tanggal. Beberapa hari dan beberapa unit dijumlahkan setelah perhitungan per mesin.
- Data sebelumnya boleh berada di luar tanggal awal, hanya sebagai pembanding. Excel tidak membuat baris harian tambahan untuk pembanding.
- Meter kosong/invalid atau pasangan tidak ada: **Data tidak tersedia**. Nol tetap nol. Selisih negatif dipertahankan dan ditandai sebagai anomali.
- Revisi terbaru pada ID/slot yang sama digunakan sekali. Draft dan laporan ditolak tidak menjadi hasil final. Pending boleh dihitung dengan label **Sementara**.

## Parameter, tanggal, dan histori

Semua 22 parameter asli dipertahankan. Parameter ke-23 adalah `oilCumulative`: Stand Pemakaian Oli Kumulatif (L). `oil` tetap Tekanan Oli (bar). Field lama `dailyOil`/`oilUsage` tidak otomatis dianggap meter kumulatif.

`production` dan `fuelUsage` asli adalah input manual per periode; hasil otomatis disimpan/ditampilkan sebagai `kwhDelta` dan `fuelDelta`, sehingga tidak menimpa input asli.

Timestamp operasional menggunakan `date`, `time`, `recordedAt` dengan offset +07:00, bersama `unitId` dan `machineId`. Waktu kirim `submittedAt` terpisah. Tanggal lama tanpa bukti tetap tidak terverifikasi; tidak diberi tanggal demo buatan.

Master tetap 78 mesin / 11 unit. PLTD Perikanan telah menjadi **PLTD Bawean**. ID Unit, ID Mesin, Kode Mesin dan SN tetap berupa teks. `machineId` internal, misalnya `kitjatim-row-10`, berbeda dari ID Mesin resmi.

## Excel sederhana

Satu worksheet **Laporan Harian**. Satu baris per mesin/tanggal. Berisi tanggal/jam, unit/mesin, empat stand, empat hasil selisih, status, dan kolom pembanding. Header tebal, border tipis, lebar kolom terukur, freeze pane, filter, angka numerik, tanggal Excel asli, dan total di bagian akhir. Tidak ada grafik atau dashboard dekoratif.

File contoh pada `test-data/PLTD_Logsheet_Contoh_2026-11-08_09.xlsx` memakai seluruh unit dalam data uji, tanggal 8–9 November 2026, jam 00:00–08:00 WIB. Total: **950 kWh / 340 L BBM / 51 jam / 8 L oli**. Data contoh bukan pembacaan operasional.

CSV tetap memuat seluruh parameter asli serta hasil harian pada record yang menjadi pasangan terpilih. PDF tetap melalui dialog cetak browser. Excel harian dan CSV detail memiliki jumlah baris berbeda karena tujuan tabelnya berbeda.

## Batas implementasi

Ini prototipe HTML interaktif; login dan peran adalah demonstrasi lokal. Belum ada autentikasi server, database bersama, atau sinkronisasi antarperangkat/APK–web. Kalkulasi, filter, penyimpanan browser, dan generator XLSX bekerja pada data yang tersedia di masing-masing prototipe.
